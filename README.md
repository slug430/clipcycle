# ClipCycle website

Public contact: clipcycle.creator@gmail.com

## Upload to GitHub

Upload every file in this folder directly into the root of the public `clipcycle` repository.
Do not upload the outer folder as a single nested folder.

## Publish with GitHub Pages

1. Open the repository.
2. Go to Settings.
3. Select Pages.
4. Under Source, choose Deploy from a branch.
5. Select `main` and `/(root)`.
6. Save.
7. Wait for GitHub to display the live website address.

Use the live addresses ending in:
- `/` for the official website
- `/privacy.html` for the Privacy Policy
- `/terms.html` for the Terms of Service
